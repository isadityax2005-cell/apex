# 🏛 Apex Residency — Luxury Real Estate Web Experience

An ultra-luxury editorial web platform for **Apex Residency**, showcasing premier architectural properties across Mumbai (Worli, Bandra, and Juhu).

## ✨ Features
- **Editorial Brand Aesthetic**: Built with Cormorant Garamond & Manrope typography, deep luxury slate/sand palettes, and brutalist architectural styling.
- **Liquid Glass UI**: Glassmorphic frosted blur treatments (`backdrop-filter: blur(16px) saturate(180%)`) with sleek pill buttons and controls.
- **Interactive Multi-Photo Carousels**: Smooth hardware-accelerated photo carousels with touch/swipe support, liquid glass navigation buttons, and expanding indicator pills.
- **Cinematic GSAP Preloader & Parallax**: Signature arch preloader animation and scroll-scrub parallax hero.
- **Expandable Amenities Showcase**: Collapsible drawers detailing exclusive property amenities, private spas, infinity pools, and specifications.
- **Ultra-Realistic 4K AI Architectural Photography**: Custom luxury interior and exterior imagery generated with Magnific AI.

## 🛠 Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS, Vanilla Glassmorphism CSS
- **Animation**: [GSAP](https://greensock.com/) & ScrollTrigger
- **Icons**: Lucide Icons
- **Language**: TypeScript

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
